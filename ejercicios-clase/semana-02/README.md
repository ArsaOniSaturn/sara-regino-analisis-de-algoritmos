# EJERCICIOS DE CLASE SEMANA 2

Este laboratorio abarca la configuración de un entorno virtual, la gestión de dependencias, 
la refactorización de código bajo estándares **PEP 8** y la implementación de un ejercicio 
sobre la clasificación de años bisiestos en Python.


## COMANDOS UTILIZADOS PARA LA CREACIÓN DE UN ENTORNO VIRTUAL

1. Crear el entorno virtual: python -m venv venv --clear --without-pip
2. Activar el entorno virtual: .\venv\Scripts\Activate.ps1
3. Instalar pip y dependencias del proyecto con requirements.txt: 
    python -m ensurepip --default-pip
    pip install -r requirements.txt
